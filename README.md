# 🧮 Calculator

A simple and user-friendly calculator mini project built using HTML, CSS, and JavaScript. ✨

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🎨 Simple and clean UI
* 📱 Responsive design

## 🛠️ Technologies Used

* 🌐 HTML
* 🎨 CSS
* ⚡ JavaScript

## 🚀 How to Run

1. 📥 Clone this repository.
2. 📂 Open `index.html` in your browser.
3. 🧮 Start calculating!
